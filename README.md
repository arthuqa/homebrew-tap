# arthuqa/homebrew-tap

Homebrew casks for [arthuqa](https://github.com/arthuqa) projects.

## datasetop

```sh
brew install --cask arthuqa/tap/datasetop
```

[Casks/datasetop.rb](Casks/datasetop.rb) is regenerated every six hours by
[`update-cask`](.github/workflows/update-cask.yml) from the latest
[datasetop release](https://github.com/arthuqa/datasetop/releases).
